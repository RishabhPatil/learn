01 / THE INTUITION

Meaning is not
the whole story.

Consider the same three tokens in two different orders. Their individual embeddings do not change, but the sentence does.

dog0bites1man2
man0bites1dog2

Unmasked self-attention, on its own, is permutation equivariant: shuffle its input rows and the output rows shuffle the same way. It has no inherent notion of “first” or “three tokens ago.” A causal mask constrains which tokens are visible, but does not explicitly encode their distance.

Positional methods supply that missing structure. We can add a signal to the input, rotate queries and keys, or bias attention scores. Let’s see all three.

A CLOSER LOOK

Three places
to put position.

01 Sinusoidal: add to the embedding

The original Transformer adds a fixed position vector to each token embedding before the first layer. Even and odd dimensions form sine–cosine pairs; their wavelengths grow geometrically. In the playground, p is position, d = 32, i indexes a pair, and B is the frequency base.

For a fixed offset, a sine–cosine pair at p + Δ is a linear transformation of the pair at p. This gives the model a useful structure for learning relative offsets. A formula defined for any position does not guarantee useful behavior beyond training lengths.

Vaswani et al., 2017 · §3.5 ↗
02 RoPE: rotate queries and keys

For each pair, multiply the query at m by R(mθ), and the key at n by R(nθ). Since rotations compose, their inner product is qᵀR((n − m)θ)k. Its positional dependence is on the offset, while its content dependence remains in q and k.

The playground isolates one pair with identical unit vectors. Real models use many pairs, with different frequencies. RoPE is not an additive input embedding, and the displayed cosine is not a complete attention score.

Su et al., 2021 · RoFormer ↗
03 ALiBi: change the attention logit

For a visible key j ≤ i, a causal head uses score(i, j) = qᵢ·kⱼ / √dₖ − sₕ(i − j). Future keys remain masked. The slope sₕ is fixed per head; it makes distant keys less favored when content scores are otherwise equal.

Strong content scores can still outweigh the penalty. The published method tests extrapolation to longer sequences, but that is an empirical result under specific training and evaluation conditions, not an unlimited-context guarantee.

Press et al., 2021 · Train Short, Test Long ↗

FROM PICTURE TO CODE

The original signal,
in a few lines.

A minimal NumPy implementation. Positions index rows; embedding components index columns. The demo above computes the same formula in JavaScript.

Inspect the playground’s math ↗
sinusoidal.py
import numpy as np

def positional_encoding(length, dim, base=10_000):
    assert dim > 0 and dim % 2 == 0
    positions = np.arange(length)[:, None]
    pairs = np.arange(0, dim, 2)
    angles = positions / base ** (pairs / dim)

    pe = np.empty((length, dim))
    pe[:, 0::2] = np.sin(angles)
    pe[:, 1::2] = np.cos(angles)
    return pe
