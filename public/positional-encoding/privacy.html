LEARNING & RESEARCH

Privacy, in plain language.

Last updated November 1, 2026. This learning site is maintained by Rishabh Patil and hosted on GitHub Pages.

Optional analytics

When Google Analytics 4 is configured, a prompt lets you accept or decline it. No Google Analytics script loads before acceptance. If it is not configured, or your browser sends Do Not Track or Global Privacy Control, this site does not load it. Preview environments do not collect analytics.

After acceptance, Google Analytics can process page visits, coarse geographic location, browser/device information, referring site, engagement, and predefined interactions such as changing an encoding method, copying code, and downloading a citation. It uses a browser identifier stored in cookies. Google receives network information needed to process requests. The site does not request your name, email, account details, or precise location.

Our analytics code removes query strings and fragments from the page URL, limits the referrer to its origin, and sends only predefined event names and method labels. Advertising storage, advertising personalization, and Google signals are disabled in our tag configuration. There are no session recordings or fingerprinting scripts.

Research atlas examples

The atlas uses fixed text and generated image examples. It has no prompt input or image upload. Calculations run locally in your browser. Analytics receives only predefined method and interaction labels, not computed coordinates. Configuration links contain the example and encoding settings; downloaded positional data stays in your local file.

Your choices

Accept or decline using the prompt. Use Analytics preferences in the homepage or guide footer to change your choice. Declining after acceptance stops future collection and deletes this learning site’s analytics cookies; data already sent is not automatically erased. Your preference applies across the /learn/ homepage and articles and is stored locally in this browser for up to 180 days. If local storage is unavailable, it applies only to the current page session.

Hosting and third-party links

GitHub may process connection logs independently of these analytics preferences. Links to papers and GitHub take you to services with their own policies. See GitHub’s privacy statement and Google’s privacy policy.

What the statistics are for

Aggregate statistics help improve the learning site and document readership and educational reach. They may be summarized in professional portfolios. Analytics do not establish a visitor’s identity, employer, expertise, or endorsement.

Contact

For general privacy questions, use the contact options on the maintainer’s GitHub profile. Do not post personal information in public GitHub issues.
