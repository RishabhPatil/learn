Definitions & sources

Scope, conventions & provenance

Inputs are illustrative activations in arbitrary units. Variance divides by the number of values, not one fewer. Normalized values z are dimensionless; final output y includes any gain/bias. JavaScript double precision evaluates the formulas locally; this is not a float16 kernel or a training simulation.

LayerNorm and RMSNorm here reduce four features per vector. BatchNorm pools samples and spatial slots per channel. GroupNorm pools grouped channels and spatial slots within one sample. A single GroupNorm group is not generally the same as feature-only LayerNorm.

BatchNorm training uses current-batch population variance. PyTorch's running-variance update uses an unbiased estimate; our fixed inference values are illustrative stored statistics, not that update. We cover tracked-stat inference; implementations can also use batch statistics at evaluation time.

These examples demonstrate arithmetic and dependencies. They do not show which method trains best, guarantee stability, make outputs Gaussian, or benchmark hardware. Conditional norms, residual placement and normalization alternatives are outside scope.
