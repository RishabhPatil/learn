## Score rationale and primary evidence

Each row explains U/V/S/D/F in that order. Citations are versioned primary sources, not popularity evidence.

1. **Normalization:** recurring in CNN/RNN/Transformer families (5); axes and centering directly visible (5); hand-solvable outputs (5); a familiar mechanism but distinct from position (4); no model downloads (5). [LN v1 §3](https://arxiv.org/pdf/1607.06450v1), [RMS v1 §4](https://arxiv.org/html/1910.07467v1), [BN v3 §3](https://arxiv.org/pdf/1502.03167v3), [GN v3 §3](https://arxiv.org/html/1803.08494v3). Full audit in [article brief](articles/normalization.md).
2. **Memory:** text and multimodal autoregressive decoders (5); grid grows visibly (5); exact element/byte counting (5); practical but widely covered (4); prefill/decode and head-sharing need careful limits (4). [GQA v3 §2](https://arxiv.org/abs/2305.13245v3). Cache counts do not establish runtime or all inference memory.
3. **Tokens:** text/image/audio representations (5); spatial grouping is concrete (5); learned projections need illustrative labels (4); establishes what position methods act on (5); two constructions require careful sequencing (4). [ViT v2 §3.1](https://arxiv.org/abs/2010.11929v2), [VQ-VAE v2 §3](https://arxiv.org/abs/1711.00937v2). Continuous vectors and discrete codes must remain distinct.
4. **Attention computation:** Transformer modalities (5); tiles reveal working memory (5); dense arithmetic oracle (5); adjacent to Position but different question (4); stable online-softmax state is harder to expose simply (3). [FlashAttention v2 §3 Algorithm 1](https://arxiv.org/abs/2205.14135v2). Exact attention is not sparse attention or bitwise-identical rounding.
5. **Quantization:** broad training/deployment uses (5); bins/clipping immediately visible (5); calibration/rounding choices affect answers (4); distinct but familiar (4); fixed tensor examples feasible (4). [Jacob et al. v1](https://arxiv.org/abs/1712.05877v1), [LLM.int8 v2](https://arxiv.org/abs/2208.07339v2). Weight, activation and cache quantization are different scopes.
6. **Residuals/gates:** convolutional, sequence and Transformer blocks (5); small Jacobian view needs care (4); exact local derivatives (5); distinct underlying mechanism (4); 2D model manageable (4). [ResNet v1](https://arxiv.org/abs/1512.03385v1), [Highway Networks v2](https://arxiv.org/abs/1505.00387v2). Learned gates are not just skip paths.
7. **Experts:** language and vision conditional computation (5); routing/capacity visible (5); algorithms vary (4); useful separate compute story (4); policy and overflow semantics require more setup (3). [Switch v3](https://arxiv.org/abs/2101.03961v3), [V-MoE v1](https://arxiv.org/abs/2106.05974v1). Active and total parameters differ.
8. **Low rank:** transfer across linear layers (4); matrix action can be visualized but abstract (4); exact multiplication/rank (5); separate adaptation story (4); tiny matrices straightforward (5). [LoRA v2](https://arxiv.org/abs/2106.09685v2). Low parameter count does not imply downstream task quality.
9. **Bottlenecks:** image/audio/video compression (5); code boundaries visible (5); learned encoders cannot be invented (4); distinct representation story (4); faithful examples need stricter scope or real weights (3). [VQ-VAE v2](https://arxiv.org/abs/1711.00937v2), [Latent Diffusion v2](https://arxiv.org/abs/2112.10752v2).
10. **Generation order:** text and visual generation (5); schedule animation strong (5); toy schedule cannot reproduce model quality (3); distinct generation story (4); accurate comparison of objectives costs scope (3). [VAR v2](https://arxiv.org/abs/2404.02905v2), [LLaDA v3](https://arxiv.org/abs/2502.09992v3). Different factorizations are not interchangeable.
11. **Conditioning:** multimodal generation (5); hidden features remain abstract (4); toy operators exact but semantics untrained (4); useful network-versus-sampler distinction (4); several architectures risk clutter (3). [FiLM v2](https://arxiv.org/abs/1709.07871v2), [Latent Diffusion v2 §3.3](https://arxiv.org/abs/2112.10752v2).
12. **Objectives:** broadly shared learning mechanisms (5); target/gradient tracing useful (4); exact losses possible but not directly comparable (4); distinct supervision story (4); dataset and loss design need narrowing (3). [BERT v2](https://arxiv.org/abs/1810.04805v2), [SimCLR v3](https://arxiv.org/abs/2002.05709v3), [DDPM v2](https://arxiv.org/abs/2006.11239v2).

## Selected shortlist and next batch

**Normalization, inference memory, tokenization** give varied mechanisms and audiences: activation arithmetic, deployment/storage, and representation construction. All have testable claims, primary sources, and useful local visualizations. No candidate clearly outweighs Normalization's complete specification and readiness. The next two recommendations are **Inference memory** and **What is a token outside language?** Neither is initiated in this batch.

Recent normalization checks include [DyT v1](https://arxiv.org/html/2503.10622v1), [numerical stability analysis v2](https://arxiv.org/html/2503.10251v2), and [centering-folding work v1](https://arxiv.org/html/2605.14521v1). They motivate careful scope, not a claim that four standard transforms are obsolete, universally necessary, or interchangeable.
